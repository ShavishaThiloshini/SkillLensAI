# SkillLens AI

**AI-Powered Resume & Skill Gap Analyzer**

> See your skills. Find your gaps. Build your career.

## Project Overview
SkillLens AI is a platform designed to help job seekers align their skills with market demands by analyzing their resumes against target job descriptions. It uses AI to identify skill gaps and provides actionable recommendations to improve career prospects.

## Main Purpose
The core objective is to empower professionals by providing personalized insights into their qualifications, highlighting areas for improvement, and bridging the gap between their current skill set and their desired roles.

## Technology Stack
- **Frontend**: React, Vite, Tailwind CSS (optional), React Router, Axios, Lucide React, Recharts
- **Backend**: Node.js, Express, MySQL, JWT, Multer
- **AI/Processing**: Integration with external AI APIs for resume parsing and analysis

## How to run frontend
1. Navigate to the frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## How to run backend
1. Navigate to the backend directory:
   ```bash
   cd backend
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create a `.env` file based on `.env.example`:
   ```bash
   cp .env.example .env
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
